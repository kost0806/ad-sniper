Ad Sniper

개인정보처리방침

최초 작성일: 2025년 6월 12일  ·  최종 수정일: 2026년 6월 15일

🔒 Ad Sniper는 사용자의 어떠한 개인정보도 수집하거나 외부 서버로 전송하지 않습니다. 모든 데이터는 사용자의 브라우저 로컬 저장소에만 보관됩니다.

1. 수집하는 정보

Ad Sniper는 사용자의 개인정보를 수집하지 않습니다. 확장이 저장하는 데이터는 다음과 같습니다:

  • 차단된 광고 목록: 사용자가 직접 차단한 광고의 식별자(광고 도메인, 요소 ID, CSS 선택자)가 브라우저의 로컬 저장소(chrome.storage.local)에 저장됩니다.
  • 비활성화된 사이트 목록: 사용자가 팝업에서 확장을 끈 사이트의 도메인이 로컬 저장소에 저장됩니다.

이 데이터는 사용자의 기기 밖으로 전송되지 않으며, 제3자와 공유되지 않습니다.

2. 권한 사용 목적

권한 사용 목적
storage 차단된 광고 목록 및 비활성화된 사이트 목록을 브라우저 로컬 저장소에 저장
declarativeNetRequest 차단된 광고 도메인의 네트워크 요청(iframe, 스크립트, 이미지 등)을 동적으로 차단·해제
tabs 팝업에서 현재 활성 탭의 도메인 확인 및 차단 해제 후 페이지 새로고침. 탭 URL·방문 기록은 수집하지 않습니다.
호스트 권한 <all_urls> 광고는 어느 웹사이트에서나 나타날 수 있으므로, 사용자가 방문하는 모든 페이지에서 광고 요소를 감지하고 차단 UI를 표시하기 위해 필요. 페이지 콘텐츠를 수집하거나 외부로 전송하지 않습니다.

3. 제3자 데이터 공유

Ad Sniper는 수집된 데이터를 제3자와 공유하지 않습니다. 외부 서버, 분석 서비스, 광고 네트워크와의 통신이 없습니다.

4. 데이터 보관 및 삭제

차단 목록은 사용자의 브라우저에만 저장되며, 다음 방법으로 언제든지 삭제할 수 있습니다:

  • 확장 팝업 → "차단 목록 관리"에서 개별 항목 삭제 또는 전체 삭제
  • Chrome 설정에서 확장을 제거하면 모든 데이터가 삭제됩니다

5. 방침 변경

본 개인정보처리방침이 변경될 경우, 이 페이지를 통해 공지합니다. 변경 사항은 페이지 상단의 최종 수정일을 통해 확인할 수 있습니다.
